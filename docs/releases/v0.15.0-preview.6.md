## macOS preview / Mac 预览版

Papergraph is now available for macOS 14 or newer, with separate downloads for Apple Silicon (`macos-arm64`) and Intel (`macos-x64`). Extract the ZIP and move `Papergraph.app` to Applications. The .NET runtime is included.

- Shared graph model, file format, layout and local agent interface with Windows; existing `.papergraph` and `.yujian` files can be opened directly.
- Mac controls: drag to select, two-finger scroll to pan, a visible Select/Pan/zoom/Actions toolbar, Command shortcuts and optional Control-click menus.
- English, Simplified Chinese and Japanese interface; light/dark themes, four Notes pages and live full text.
- Windows and Mac now share the same sun/moon artwork and white rounded application icon.
- Includes a Windows x64 preview with the shared icon changes. Windows 0.14.3 remains the stable release.

Mac graphs are saved in `~/Library/Application Support/Papergraph`; Windows graphs remain in the `Data` folder beside the executable. Copy your graph files locally and keep a backup before switching between previews. Application archives contain no personal graphs or library state.

**Preview limitations:** the Mac app is ad-hoc signed, without Apple Developer ID signing or notarization. macOS may block the first launch; follow [Apple's instructions for an app from an unidentified developer](https://support.apple.com/en-us/102445) if you choose to open this download. Intel is cross-built and has not been tested on Intel hardware. Physical trackpad pinch and Chinese/Japanese IME composition still need hands-on verification.

Source and release packages are built from the same tagged commit. The release workflow requires the Windows and macOS test jobs to pass before publishing all three archives and `SHA256SUMS.txt`.

### 中文

本次新增 Mac 预览版，支持 macOS 14 及以上。M 系列芯片请选择 `macos-arm64`，Intel 芯片请选择 `macos-x64`；解压后把 `Papergraph.app` 拖入“应用程序”，无需另装 .NET。

支持原有图文件、分类、四页笔记、实时全文和本地 Agent 接口，并增加适合 Mac 的拖动选择、双指平移、Command 快捷键和可见操作菜单。太阳、月亮和白底圆角应用图标已在 Windows、Mac 两端统一。

这是预览版：Mac 程序尚未经过 Apple Developer ID 签名和公证，首次打开可能被系统拦截；Intel 包尚未进行实机验证。Windows 0.14.3 正式版继续保留。详细操作见 [Mac 使用说明](https://github.com/wangyuer1-lang/papergraph/blob/main/docs/macos.md)。
