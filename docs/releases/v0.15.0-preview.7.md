## Papergraph v0.15.0-preview.7

This update fixes mouse access to the macOS proposition editor and standardizes the project documentation.

- **macOS editor fix:** a hidden relation-settings viewport could intercept clicks over the proposition body. Clicking a proposition or frame's body now focuses the text editor, including after selecting a relation.
- **Interaction coverage:** regression tests resolve the rendered click target, focus the editor and send text input. They cover titles, proposition and frame bodies, all four Notes pages, relation notes, light/dark themes, manuscript updates and saving.
- **Documentation:** English and Chinese READMEs now use consistent Papergraph naming, section structure and platform-specific download tables.

### Downloads

| Package | Platform |
| --- | --- |
| `macos-arm64` | macOS 14 or newer, Apple Silicon (M series) |
| `macos-x64` | macOS 14 or newer, Intel |
| `windows-x64` | Windows x64 preview |

The .NET runtime is included. For macOS, extract the ZIP and move `Papergraph.app` to Applications. Graph files remain in `~/Library/Application Support/Papergraph`. Preserve the `Data` folder beside the executable when upgrading on Windows. Windows v0.14.3 remains the stable release.

The macOS preview is ad-hoc signed, without Apple Developer ID signing or notarization. See the [macOS guide](https://github.com/wangyuer1-lang/papergraph/blob/main/docs/macos.md#download-and-install) for first-launch instructions. Intel execution, physical trackpad pinch and Chinese/Japanese IME composition still require hands-on verification.

### 中文说明

本次修复 macOS 右侧正文编辑框点击无响应的问题：原先隐藏的关系设置滚动层会挡住正文框，导致点击无法进入编辑。修复后，命题及方框正文可正常点击输入，切换连线后再返回也可继续编辑。

新增测试覆盖标题、正文、四页笔记、连线笔记、深浅主题、实时全文更新与保存。中英文 README 同步统一了项目名称、章节结构和平台下载入口。

M 系列 Mac 请选择 `macos-arm64`，Intel Mac 请选择 `macos-x64`。这是预览版，尚未经过 Apple 公证；Intel 包尚未进行实机验证。Windows v0.14.3 正式版继续保留。
