# Papergraph 0.16.0-preview.8 — Windows and macOS

## 本次更新

- **全文直接编辑：**Mac 和 Windows 均可在 Full text 中编辑正文或括号内引用，修改自动保存到来源命题，重复引用一同更新，支持撤销和重做。自动生成的标点与跨命题修改受到保护。
- **引用自动背景高亮：**单向虚线箭头由引用材料指向正文，引用文字跟在正文后的括号内。引用及括号使用淡柠檬黄背景，深色模式使用暗柠檬色，与红、橙、绿、蓝、紫字体颜色区分开；保留原有字体颜色。
- **鼠标和触摸板：**Mac 在画布空白处左键拖动平移，Shift＋拖动或右键拖动框选；鼠标滚轮缩放，触摸板双指滑动平移。两端都有缩放、操作菜单和临时平移快捷键。
- **图谱管理：**未分类图谱直接放在侧栏，移除固定的 Unfiled 分类；保留自定义分类、自动保存、备份及 Markdown 导出。
- **手动局域网同步：**两台电脑连接同一网络，打开“文件 → 设备同步”，输入配对码、比较改动并在双方确认后同步。兼容的改动自动合并，冲突可保留两份，无需账号或云服务器。
- **文字颜色与 AI 只读保护：**支持命题文字局部着色；图谱旁的锁可阻止 Agent 修改，同时保留作者手动编辑能力。界面支持英文、简体中文和日文。

本次仅发布 Mac／Windows。没有更新或公开安卓源码，也没有新的安卓 APK。

## Downloads and installation

- Windows x64: `Papergraph-0.16.0-preview.8-windows-x64.zip`. Extract the complete archive, then run `papergraph.exe`. Preserve the existing `Data` folder or custom library when upgrading.
- Apple Silicon Mac: `Papergraph-0.16.0-preview.8-macos-arm64.zip`. Intel Mac: `Papergraph-0.16.0-preview.8-macos-x64.zip`. Quit the app before replacing `Papergraph.app` in Applications; the library is stored separately.
- All three packages include the runtime. Checksums are in `SHA256SUMS.txt`.

## Changes

Both desktop apps now support direct manuscript editing, source-linked parenthetical citations, automatic citation background highlighting and selected proposition font colors. Editing repeated citations, undo/redo and switching themes keep highlights aligned with the source. Display highlights do not alter saved text or plain-text copying.

This update also brings the latest canvas controls, unassigned graphs at the sidebar root, per-graph agent protection and manual LAN pairing/comparison/synchronization to the public desktop repository. Its existing MIT license is retained.

## Validation and preview limits

The release workflow requires native macOS and Windows regression tests, Full text editing/reference checks, and synchronization merge/recovery/loopback TLS checks before publishing. The existing public Mac inspector click/input regression test is retained alongside the newer desktop tests.

Mac packages use ad-hoc signatures and are not notarized. The Intel package is cross-built and still needs hardware testing. Real Windows–Mac networking/firewall behavior and interactive Chinese/Japanese IME candidate windows need hands-on validation. Guest Wi-Fi may block devices from reaching one another.

The experimental Mac Bluetooth adapter remains included, but physical Android–Mac transfer still needs testing. This desktop-only release provides no Android app or source and no Windows Bluetooth support. Use LAN sync between desktop apps.
